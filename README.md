# Nitro Velocity 3D
A free browser-based 3D racing game built with Three.js. The game is static and can be deployed as a Render Docker Web Service using the included Dockerfile.

Controls: W/Arrow Up accelerate, S/Arrow Down brake/reverse, A/D or Left/Right steer, Space nitro, P pause. Mobile touch controls are included.

The 3D engine is loaded from the Three.js CDN at runtime, so an internet connection is required when playing the hosted/downloaded HTML version.
